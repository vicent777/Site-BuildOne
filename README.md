# 💻 Sobre o Projeto
Este projeto consiste no desenvolvimento de uma Landing Page de Alta Conversão para uma marca de vestuário e materiais esportivos personalizados.

O objetivo principal da aplicação é funcionar como um catálogo digital e canal de captação de clientes (leads), conectando o público-alvo diretamente ao setor de vendas da empresa (modelo On-Demand / B2B e B2C)
